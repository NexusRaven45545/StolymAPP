## Installation

### iOS/iPadOS (Sideloading)

#### Method 1: Sideloadly (Windows/macOS)

1. Download [Sideloadly](https://sideloadly.io)
2. Install **Apple Devices** from Microsoft Store (Windows only)
3. Connect your iPhone/iPad via USB
4. Download the latest `.ipa` from [Releases](https://github.com/ryvione/StolymAPP-IOS/releases)
5. Open Sideloadly and drag the IPA file
6. Enter your Apple ID credentials (stored locally and securely)
7. Click **Start** and wait for installation to complete

**Note:** You may need to trust the developer certificate in Settings > General > VPN & Device Management

#### Method 2: iLoader (Linux - Debian-Based)
**Note: This program is compatible with all Linux distros, we just showed only for Debian.**

1. Visit [iLoader Releases](https://github.com/nab138/iloader/releases)
2. Download the latest `.deb` package
3. Install the package: `sudo dpkg -i iloader_*.deb`
4. Install dependencies: `sudo apt-get install -f`
5. Launch iLoader and connect your device
6. Sign in with your Apple ID on the left panel
7. Click **Import IPA** on the right panel
8. Select the StolymAPP IPA and click **Install**

**Dependencies:** Check the [iLoader repository](https://github.com/nab138/iloader) for full requirements

#### Method 3: AltStore (All Platforms)

1. Install [AltStore](https://altstore.io) on your computer
2. Connect your device and enable AltServer
3. Download the IPA from Releases
4. Open AltStore on your device and tap the + icon
5. Select the downloaded IPA to install

## Version Policy

Stolym Studios follows a strict versioning and release policy:

- **No Version Skipping** — All version numbers are sequential and meaningful
- **Stability First** — Only tested and functional builds are released
- **Transparency** — Internal builds may exist but are not published if unstable
- **Semantic Versioning** — Major.Minor.Patch format
  - **Major:** Significant features or breaking changes
  - **Minor:** New features and improvements
  - **Patch:** Bug fixes and small updates

**Example:** Alpha 3.3 indicates:
- Alpha stage of development
- Version 3 (major)
- Update 3 (minor)
